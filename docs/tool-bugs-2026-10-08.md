# Tool bug fixes, 8 October 2026

Reviewed the square editor, social resizer, converter, compressor, cropper,
upscaler, calculator, and their shared image utilities. Existing checkout
changes were preserved.

## Changes

- Keep image URLs alive while the upscaler's original and comparison previews
  use them. Release upload URLs on replacement, reset, clear, and unmount.
- Cancel replaced image loads so an older upload cannot overwrite a newer
  image in the square editor, cropper, or upscaler.
- Reset converter and compressor file inputs after each selection so the same
  file can be selected again. Show feedback for rejected images and apply the
  converter's 30 MB upload limit.
- Discard converter/compressor results for removed files, cleared batches, or
  changed settings. Clear retry errors and release processing flags in finally
  blocks.
- Keep both compressed images when their filenames collide in a ZIP. Add
  numbered suffixes and report ZIP generation failures.
- Show a plus sign when compression produces a larger file.
- Attach cropper wheel zoom after upload, align slider/button/wheel limits at
  1000%, and preserve selected ratios when changing a small crop.
- Fill transparent areas with white in square/resizer JPEG exports, including
  cropped images and rounded corners.
- Preserve non-native platform sizes and cleared presets in resizer URLs, back
  navigation, and reloads. Avoid adding duplicate history entries.
- Clamp limited exports to at least one pixel per dimension and report missing
  canvas contexts or failed upscaler previews without offering stale results.

The calculator's dimension validation, ratio calculation, resize calculation,
and event deduplication passed the existing regression checks.

## Validation

- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`, all 56 static pages generated
- `scripts/verify-tools.py`, Chromium and WebKit, including file signatures,
  dimensions, alpha, exact crop pixels at DPR 1/2, target compression sizes,
  invalid inputs, calculator boundaries, and preset history
- `scripts/verify-tool-bugs.py`, targeted browser checks for the changes above
- Mobile overflow checks at 390 pixels for all seven tool pages

The original browser suite's analytics allowlist was updated to include the
existing fixed device/layout/editor labels. Filename and image-data checks
remain in place.

## External and test limitations

StartupBar's external iframe emits a React hydration error from
`https://startupbar.co/assets/index-Ci2T26ln.js`. Blocking StartupBar removes
that error; SquarePic's own tool code does not produce it. The new regression
suite isolates the widget. Its hosted code is outside this repository.

WebKit can report access-control errors for background Next.js RSC requests
while navigating between test cases. The new suite records those separately
from JavaScript exceptions and still verifies every tool action and export.

AVIF, BMP, GIF, and TIFF output remain disabled by the existing converter.
The enabled JPEG, PNG, WebP, and ICO exports were verified.
